## 📌 نبذة عن المشروع

**Traffic Tracker (راصد حركة الشبكة)** هو تطبيق متقدم ومفتوح المصدر مخصص لتشخيص وفحص شبكات الهواتف الذكية والتدقيق الأمني المباشر على نظام أندرويد. تم بناؤه باستخدام واجهة تفاعلية حديثة بأطر **Flutter** ومدعوم بمحرك أصلي (Native Kotlin) يعتمد على خدمة `VpnService` الخاصة بنظام أندرويد.

### المشكلة التي يعالجها
يواجه مطورو التطبيقات ومختبرو الأمان والشبكات صعوبات بالغة عند فحص حزم الشبكة في بيئة أندرويد:
1. **اشتراط كسر الحماية (الروت - Root)**: تتطلب أغلب أدوات التقاط الحزم المنخفضة (مثل `tcpdump`) صلاحيات الروت، مما يمنع تشغيل التطبيقات البنكية ويخل بأمان النظام.
2. **تعقيد شهادات فك التشفير وتثبيت الشهادات (SSL Pinning)**: تتطلب أدوات البروكسي التقليدية (مثل Charles أو Burp) تثبيت شهادات جذرية وتعديل إعدادات أمان الشبكة يدويًا داخل كود التطبيقات.
3. **التشويش والازدحام في البيانات**: ترسل أنظمة الهواتف مئات الطلبات في الخلفية عبر خدمات النظام ومتجر التطبيقات، مما يصعب تتبع طلبات تطبيق محدد قيد الاختبار.

### الحل المقدم
يقدم **Traffic Tracker** حلاً متكاملاً دون الحاجة لأي روت:
* ينشئ واجهة شبكة افتراضية محلية (`TUN Interface`) تعترض حزم الـ IP وتقرأ استعلامات الـ DNS وترويسات مصافحة TLS (`SNI`) لحظيًا.
* يوفر وضع العزل المتقدم (**Target Mode**) لتحديد تطبيق أو عدة تطبيقات وحصر التقاط الحزم عليها فقط.
* يسجل الحزم الخام في ملفات بصيغة **PCAP القياسية** الجاهزة للفتح المباشر والتحليل الجنائي في برنامج **Wireshark**.

### الفئة المستهدفة
* **مطورو تطبيقات الهواتف الذكية**: لفحص وتصحيح استدعاءات الـ REST API، مراقبة وقت الاستجابة، وفحص ترويسات الطلبات.
* **باحثو الأمن السيبراني واختبار الاختراق**: لاكتشاف النطاقات السرية في التطبيقات، فحص إعدادات TLS، والتحقق من عدم تسريب بيانات حساسة.
* **مهندسو الجودة والاختبار (QA)**: لمحاكاة سيناريوهات الأخطاء (4xx و 5xx) وتوليد أوامر `cURL` فورية لمشاركتها مع فرق التطوير.
* **المهتمون بالخصوصية وحماية البيانات**: لمعرفة وجهات وخوادم الاتصال التي تتواصل معها التطبيقات في الخلفية.

## ✨ المميزات الرئيسية

### 1. 🛡️ فحص شبكة النظام بالكامل (بدون روت)
* **واجهة TUN محلية آمنة**: تعتمد على `android.net.VpnService` الرسمي دون تعديل أي ملف في النظام.
* **إعادة توجيه حزم شفافة**: تمرير حزم البيانات للإنترنت دون انقطاع الاتصال أو بطء ملحوظ.
* **كشف النطاقات عبر SNI**: استخراج اسم الخادم (Server Name Indication) من حزمة `TLS Client Hello` دون المساس بالتشفير ودون الحاجة لتنصيب شهادات CA.
* **تحليل استعلامات DNS**: كشف استعلامات UDP عبر المنفذ 53 لربط عناوين الـ IP بالنطاقات البشرية فوراً.
* **تفاصيل المقابس (Sockets)**: كشف بروتوكول النقل (TCP/UDP/ICMP)، المنافذ المحلية والبعيدة، أحجام البيانات، والوقت بدقة متناهية.

### 2. 🎯 حصر الفحص على تطبيقات محددة (Target Mode)
* **فلترة صارمة للتطبيقات**: استبعاد حركة مرور النظام وعزل التطبيقات المحددة فقط.
* **تصنيف ذكي**: تبويب التطبيقات إلى تطبيقات مستخدم وتطبيقات نظام.
* **مزامنة فورية حية**: تنطبق التغييرات في قائمة التطبيقات على تيار الفحص المباشر فوراً دون إعادة تشغيل الـ VPN.
* **بحث واختيار جماعي**: إمكانية البحث باسم التطبيق أو اسم الحزمة مع أزرار تحديد/إلغاء الكل بنقرة واحدة.

### 3. 🔍 فاحص طلبات الـ HTTP / REST API المدمج
* **اعتراض دقيق لطلبات الـ HTTP**: تسجيل كامل للترويسات والبيانات وحالات الاستجابة وأزمنة التأخير.
* **توليد أوامر cURL فورية**: زر لنسخ أمر `cURL` كامل مع كافة الترويسات والبيانات لاختباره فوراً في الطرفية أو استيراده في أدوات مثل Postman.
* **عارض JSON تفاعلي متقدم**: عارض منسق لحمولة البيانات يدعم الطي والنسخ والبحث.
* **منصة اختبارات تجريبية مدمجة (Sandbox)**: إرسال طلبات اختبارية مباشرة (`GET 200`, `POST JSON`, `PUT`, `DELETE`, `302 Redirect`, `404`, `500`) مع إمكانية إرسال طلبات مخصصة بالكامل.

### 4. 💾 تصدير ملفات PCAP القياسية لبرنامج Wireshark
* **تسجيل ثنائي وفق مواصفات Libpcap القياسية**: ملفات متوافقة بنسبة 100% مع **Wireshark** و **Zeek** و **NetworkMiner**.
* **مرونة اختيار موقع الحفظ**: حفظ الحزم في مجلد التنزيلات (Downloads)، المستندات، مجلد التطبيق الخارجي، أو أي مجلد يحدده المستخدم عبر واجهة تخزين أندرويد (SAF).

### 5. 🎨 تصميم Material 3، سمات لونية متعددة ودعم كامل للغة العربية
* **Material You**: تكامل اختياري مع ألوان خلفية وثيم نظام أندرويد 12 فما فوق.
* **6 سمات لونية منتقاة**: الأخضر الغابي، الأحمر القرمزي، الأزرق المحيطي، البنفسجي الملكي، البرتقالي، والزمردي.
* **أوضاع المظهر**: دعم كامل للوضع الفاتح، الوضع الداكن، والوضع التلقائي للنظام.
* **واجهة عربية أصيلة (RTL)**: دعم كامل لاتجاه الواجهات من اليمين لليسار، خط **Readex Pro** المخصص، وتوجيه الأسهم التفاعلية بحسب اللغة.
* **إدارة تحسين استهلاك البطارية**: وصول بنقرة واحدة لإيقاف قيود Doze ومنع إيقاف الفحص عند إغلاق الشاشة.

## 📖 دليل الاستخدام

1. **مراقبة الشبكة العامة للجهاز**:
   - انتقل إلى تبويب **مراقب شبكة الجهاز (System VPN)**.
   - اضغط على **"بدء فحص ومراقبة شبكة الجهاز"**.
   - وافق على نافذة نظام أندرويد لطلب إنشاء اتصال VPN.
   - ستظهر الحزم المتدفقة لحظياً مع بيانات المنافذ والبروتوكول والنطاق.
2. **حصر الالتقاط على تطبيق معين**:
   - اضغط على زر التعديل أو شريط **"التطبيقات المستهدفة"**.
   - ابحث عن التطبيق المطلوب واضغط عليه لتحديده.
   - بالعودة للشاشة الرئيسية، سيقتصر الالتقاط على هذا التطبيق حصراً.
3. **تصدير ملف PCAP للتحليل عبر Wireshark**:
   - بعد الانتهاء من جلسة الالتقاط، اضغط على زر **"تحميل PCAP"**.
   - سيتم حفظ الحزم الملتقطة في مجلد التنزيلات بالجهاز.
   - انقل الملف لحاسوبك وافتحه مباشرة ببرنامج Wireshark لمشاهدة تفريغ الحزم وتحليل الجلسات.
4. **فحص الـ REST API وتصدير cURL**:
   - انتقل إلى تبويب **فاحص الـ API**.
   - أرسل طلباً تجريبياً أو مخصصاً واضغط عليه لعرض الترويسات والبيانات.
   - اضغط على زر **"نسخ أمر cURL"** لاستخدامه في سطر الأوامر أو استيراده في Postman.

## 🛡️ الأمان والخصوصية وتدقيق الصلاحيات

### ضمانات المعالجة المحلية 100% وانعدام التتبع
* **غياب خدمات التتبع والتحليلات**: التطبيق خالٍ تماماً من Google Analytics أو Firebase أو Sentry أو أي مكتبة تتبع طرف ثالث.
* **معالجة محلية بالكامل**: تتم معالجة الحزم وفحصها وتدوينها في ذاكرة الجهاز المؤقتة فقط، ولا يتم إرسال أي معلومة إلى أي خادم خارجي.

### استخراج SNI بدون فك تشفير البيانات أو شهادات مشبوهة
* التطبيق **لا يقوم باعتراض أو فك تشفير بيانات HTTPS (No MITM)** للتطبيقات الأخرى، بل يستخرج اسم النطاق فقط من حزمة مصافحة TLS العلنية (`SNI`) لضمان عدم تعريض كلمات المرور أو الجلسات البنكية للمستخدم لأي خطر.

### جدول تبرير صلاحيات أندرويد

| الصلاحية | التبرير التقني والاستخدام الفعلي |
|---|---|
| `BIND_VPN_SERVICE` | لازمة لإنشاء واجهة الـ TUN الافتراضية والتقاط حزم الـ IP عبر نظام أندرويد. |
| `INTERNET` | إعادة توجيه الحزم للإنترنت لمواصلة التصفح، وإرسال الطلبات التجريبية في فاحص الـ API. |
| `ACCESS_NETWORK_STATE` | التحقق من وجود اتصال شبكة نشط قبل تفعيل الـ VPN لمنع توقف الاتصال. |
| `FOREGROUND_SERVICE` | استمرار خدمة الفحص في الخلفية عند التبديل لتطبيقات أخرى. |
| `FOREGROUND_SERVICE_SPECIAL_USE` | الالتزام بسياسات أندرويد 14 لخدمات الفحص والتشخيص الشبكي. |
| `POST_NOTIFICATIONS` | إظهار إشعار النظام الإلزامي مع عداد الحزم وزر الإيقاف السريع (أندرويد 13+). |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | طلب استثناء التطبيق من الإيقاف الإجباري عند إغلاق الشاشة أثناء الفحص المطول. |
